ABOUT ME

Engineering systems from measurement to intelligence.

Automation, data and intelligent engineering systems are at the core of my work.

I'm a Master's student in Automation & IT at Technische Hochschule Köln, Germany, with a Bachelor's degree in Instrumentation & Control Engineering.

My engineering interests lie at the intersection of industrial automation, control systems, data acquisition, machine learning, signal processing and energy systems. I enjoy transforming physical measurements and engineering problems into reliable software-based solutions.

My projects combine industrial technologies such as Siemens automation, PLC/SCADA and Industrial IoT with modern data-driven approaches including Python, machine learning, digital signal processing and time-series analysis.

I am particularly interested in developing engineering systems that connect the physical world with software, analytics and intelligent decision-making — from electrical energy monitoring and forecasting to signal-based detection and renewable-energy modelling.

01

Non-Intrusive Load Monitoring

Siemens SENTRON PAC4200 + Machine Learning

Developed a Non-Intrusive Load Monitoring system capable of identifying individual electrical appliances from aggregate measurements obtained from a Siemens SENTRON PAC4200 power meter.

Key Highlights

  • Real-world electrical data acquisition using Siemens SENTRON PAC4200
  • Feature engineering from active/reactive power, current distortion, power factor and transient behaviour
  • Random Forest classifier for appliance identification
  • Real single-appliance recordings used for verification
  • Complete measurement, feature extraction, classification and visualization pipeline

03

Morse Code Audio Decoder

Python + DSP + Adaptive WPM Detection

Developed a real-time Morse code audio decoder using digital signal processing and adaptive timing analysis to detect, decode and interpret Morse signals from audio input.

Key Highlights

  • WAV, MP3 and microphone audio input
  • FFT-based carrier-frequency detection
  • Butterworth bandpass filtering
  • Hilbert-envelope based signal processing
  • Adaptive Words Per Minute (WPM) estimation
  • Real-time Morse signal detection and decoding
  • Character-level N-gram language modelling
Python NumPy SciPy FFT DSP Signal Detection

05

Industrial Water Tank Monitoring System

Siemens S7-1200 + TIA Portal + Node-RED + InfluxDB + Grafana

Developed an Industrial IoT-based water tank monitoring and control system integrating Siemens S7-1200 PLC simulation, Node-RED, InfluxDB and Grafana for real-time process monitoring, control and historical data visualization.

Key Highlights

  • Designed PLC-based tank simulation and control logic using Siemens TIA Portal and S7-1200
  • Monitored tank level, pressure and temperature together with pump, valve and cooling-fan states
  • Integrated Node-RED for real-time PLC communication, data acquisition and operator controls
  • Implemented InfluxDB for time-series process data storage and historical logging
  • Developed Grafana dashboards for real-time monitoring and process trend analysis
  • Implemented alarm detection, setpoints and PLC heartbeat monitoring
